## 六大功能指南

### 1. 💬 对话式库存操作

**【操作路径】** 点击右下角 💬 悬浮按钮 → 打开 AI 助手面板

**【示例多轮对话】**
```
你：截止阀还有多少
AI：当前"截止阀"库存情况：DN50 PN16 库存3只（⚠️告急）...
你：DN50的
AI：截止阀 GB/T587 DN50 PN16，当前库存3只。
你：这个出3个给机务组
AI：✅ 已出库 ×3，剩余库存 0
```

**【预期结果】** 支持查库存、入库、出库、撤销；多轮指代（"这个""上面的"）自动解析；操作结果绿色卡片展示。

---

### 2. 📷 拍照识别入库

**【操作路径】** 💬 AI 助手面板 → 点击 📷 按钮 → 选择/拍摄送货单图片

**【示例】** 上传一张含"截止阀 DN50 ×6、蝶阀 DN200 ×4"的送货单照片

**【预期结果】** AI 自动识别品名/规格/数量，展示识别结果卡片，确认后一键批量入库。

---

### 3. 📊 项目×备件联动分析

**【操作路径】** 顶部导航 →「📊 联动分析」tab

**【页面内容】**
- 🧠 AI 分析卡片：300字决策语言洞察（具体到节点+缺什么+建议动作）
- 📅 节点时间轴表：风险三档灯（🔴≤14天紧急 / 🟡>14天缺货 / 🟢无风险）
- 📈 ECharts 柱状图：各类别库存 vs 告急种数
- ⚠️ 风险明细表：缺货备件清单

**【预期结果】** 系泊试验（14天内）显示🔴，航行试验/分段制造显示🟡。

---

### 4. 📧 AI 邮件助手

**【操作路径】** 顶部导航 →「📧 邮件助手」tab

**【示例对话】**
```
你：帮我催一下蓝海阀门的截止阀
AI：已为您起草邮件致蓝海阀门·王经理，请查看草稿。
你：语气再强硬一点
AI：已按要求修改邮件（第2版）。
你：加一句不按时到货会影响系泊试验
AI：已按要求修改邮件（第3版）。
```
点击草稿卡片「📤 发送」→ 确认弹窗 → 真实发送至沙箱邮箱

**【页面结构】** 左侧：📮 沙箱收件箱（真实邮件）+ 📁 演示往来（虚构线程）；右侧：对话起草区 + 可编辑草稿卡片

---

### 5. 🧾 月末对账

**【操作路径】** 顶部导航 →「🧾 对账」tab

**【操作流程】**
1. 选择供应商（蓝海阀门）+ 月份（2026-07）
2. 上传对账单图片 → 点击「🔍 开始对账」
3. 等待 AI 识别 → 差异报告表格（✅绿=一致 / ❌红=数量不符 / ⚠️黄=单边记录）
4. 下方对话区追问："数量不符那行怎么回事"
5. 输入"生成对账结果邮件" → 草稿卡片 → 发送至沙箱

**【预期结果】** 差异精准命中，追问给出双方具体数字对比，邮件含差异清单+处理建议。

---

### 6. 🎤 全语音链路

**【操作路径】** 💬 AI 助手面板 → 按住 🎤 按钮说话 → 松开

**【示例】** 按住说"球阀还有多少" → 松开 → 自动识别 → 自动发送 → AI 回复 → 语音播报

**【预期结果】** 按钮录音中变红+脉冲动效；识别结果自动填入并发送；AI 回复自动 TTS 播报。

## 移动端说明

- 表格/图表在 ≤600px 宽度下支持**横向滑动**（overflow-x:auto），不叠字不截断
- 🎤 麦克风按钮需要**安全上下文**（HTTPS 或 localhost），裸 HTTP 下按钮自动隐藏
- 邮件助手在移动端自动切换为上下布局（线程列表在上，起草区在下）

## FAQ

**Q：🎤 麦克风按钮灰色/不可用？**
A：浏览器安全策略要求麦克风仅在 HTTPS 或 localhost 下可用。本地开发用 localhost 访问即可；生产部署需配置 HTTPS 证书。

**Q：邮件发去哪了？**
A：所有邮件只发往沙箱演示邮箱（yuanyangdemo@163.com 自身）。代码中硬编码白名单校验，不可能发往任何其他地址。在「📧 邮件助手」→「📮 沙箱收件箱」可看到刚发的邮件。

**Q：AI 回复很慢/失败怎么办？**
A：所有 AI 功能均有降级策略——简报失败降级为纯数据、邮件起草失败生成模板、TTS 失败用浏览器内置语音。文字对话功能始终可用。

**Q：数据是真实的吗？**
A：全部虚构。船舶"远洋01/02"、供应商"蓝海阀门"等均为演示数据，详见仓库 DEMO_DATA.md。
